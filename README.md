# The Walnut Workshop

Create a professional, elegant website for an antique furniture-making company, showcasing handcrafted wooden furniture, restoration, and traditional craftsmanship.

Design: Vintage luxury with a warm, timeless aesthetic. Use dark walnut brown, cream, muted beige, and deep forest green. Choose elegant serif typography, refined layouts, and subtle animations.

Images: Make the website highly visual, with many large, high-quality images of antique cabinets, carved wooden chairs, vintage tables, wardrobes, furniture details, woodworking, and artisans in their workshop. Use beautiful image grids and gallery sections.

Sections: Home with a striking hero image, Our Collection, Custom Furniture, Restoration & Craftsmanship, About Us, and Contact.

Functionality: Add simple navigation, image galleries, clear buttons, and a contact form. Make it responsive on mobile and desktop.

Important: Build the complete front end quickly. Prioritize the visual design, images, layout, and working navigation. Use existing online furniture imagery and realistic sample content. Keep the code simple and avoid unnecessary complex features. Make it look like a real, established antique furniture brand—not a generic template.
